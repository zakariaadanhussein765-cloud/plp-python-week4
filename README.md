# Week 4 Assignment: Hands-On Lab — Grades, Eligibility & Smart Decisions
This repository contains my Week 4 Python assignment for the Power Learn Project.

* `grade_classifier.py` — Classifies a student's score from 0 to 100 into grades A, B, C, D, or F.
* `eligibility_checker.py` — Checks whether a person is eligible to join a coding club based on age and parental consent.
* `atm_menu.py` — Simulates an ATM PIN check and withdrawal using nested conditional statements.
* `screenshots/` — Contains screenshots showing the programs running with different test cases.

### When is `elif` better than several separate `if` statements?

`elif` is better when only one condition should be selected from several possible choices. It checks the conditions in order and stops after finding the first true condition. This is useful for situations such as assigning grades, where a score should receive only one grade.
